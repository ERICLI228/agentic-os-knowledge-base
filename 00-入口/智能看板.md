# 📊 智能看板

> 自动更新 · DataView 驱动

---

## 📥 待处理原始资料

```dataview
TABLE file.ctime as "创建时间", file.size as "大小"
FROM "raw"
SORT file.ctime desc
```

---

## 📅 本周活跃笔记

```dataview
TABLE file.mtime as "最后修改", file.folder as "位置"
FROM "wiki" or "projects" or "daily"
WHERE file.mtime >= date(today) - dur(7 days)
SORT file.mtime desc
```

---

## 🏷️ 按标签分类

```dataview
TABLE rows.file.link as "笔记"
FROM -"archive"
FLATTEN tags as tag
GROUP BY tag
SORT rows.file.name asc
```

---

## 📋 项目状态

```dataview
TABLE status as "状态", created as "创建时间"
FROM "projects"
WHERE status
SORT status desc
```

---

## 🗂️ 各目录笔记数

```dataview
TABLE length(rows) as "笔记数"
FROM -"archive"
GROUP BY file.folder
SORT length(rows) desc
```

---

## 📌 未分类笔记（无标签）

```dataview
TABLE file.folder as "位置"
WHERE length(file.tags) = 0 AND file.folder != "templates"
SORT file.folder asc
```

---

## 🕐 最新日志

```dataview
TABLE file.cday as "日期"
FROM "daily"
SORT file.cday desc
LIMIT 10
```
