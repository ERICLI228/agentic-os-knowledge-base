### Step 2: 获取AccessKey

**操作位置**: 阿里云控制台顶部 → **AccessKey管理**

**创建步骤**:
```
1. 点击 "创建AccessKey"
2. 安全验证（手机/短信）
3. 显示:
   - AccessKey ID: LTAI5t... (可公开)
   - AccessKey Secret: ... (绝密！立即保存)
```

**⚠️ 安全存储**:
```bash
# 创建配置文件
nano ~/.openclaw/.env.sambert

# 内容:
ALIYUN_ACCESS_KEY_ID=你的AccessKey_ID
ALIYUN_ACCESS_KEY_SECRET=你的AccessKey_Secret_绝密
ALIYUN_APP_KEY=创建项目后的AppKey
ALIYUN_REGION=cn-shanghai

# 权限设置
chmod 600 ~/.openclaw/.env.sambert
```

## 🔧 配置文件创建命令

**用户执行**:
```bash
# 1. 创建配置文件
cat > ~/.openclaw/.env.sambert << 'EOF'
ALIYUN_ACCESS_KEY_ID=从控制台获取
ALIYUN_ACCESS_KEY_SECRET=从控制台获取_绝密
ALIYUN_APP_KEY=创建项目后获取
ALIYUN_REGION=cn-shanghai
EOF

# 2. 设置权限（绝密）
chmod 600 ~/.openclaw/.env.sambert

# 3. 添加到.gitignore（防止泄露）
echo ".env.sambert" >> ~/.openclaw/.gitignore
```
