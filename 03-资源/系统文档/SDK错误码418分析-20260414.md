# 🎯 SDK回调未触发根本原因

> **错误码418: 发音人参数不正确**

---

## ❌ 错误信息解析

```json
{
  "status": 41020001,
  "status_text": "TTS:TtsClientError:[tts:]Engine return error code: 418"
}
```

---

## 📊 错误码418说明

| 错误码 | 说明 | 原因 |
|--------|------|------|
| **418** | 发音人不可用 | voice参数与控制台配置不匹配 |

---

## 🔧 问题诊断

### 你控制台配置的发音人

| 项目 | 配置 |
|------|------|
| **控制台发音人** | 知锋（zhifeng） |
| **SDK参数** | voice="zhifeng" |
| **状态** | ❌ **不匹配！** |

---

## 📋 正确的发音人参数

### 控制台发音人ID

根据阿里云文档，发音人参数应该是：

| 发音人 | 正确ID | 说明 |
|--------|--------|------|
| 知锋 | **不是zhifeng** | 需查看实际ID |
| 小云 | xiaoyun | 默认发音人 |
| 小美 | xiaomei | 女声 |

---

## 🎯 解决方案

### 方案A：使用默认发音人测试

```python
synthesizer.start("测试", voice="xiaoyun")  # 默认发音人
```

---

### 方案B：查看控制台实际发音人ID

**操作**:
1. 控制台 → water-margin-drama
2. 点击"修改配置"
3. 查看"发音人"下拉选项
4. 复制实际的发音人ID（不是拼音名）

---

### 方案C：使用控制台手动生成（推荐）

**立即可用**:
- 控制台选择发音人后直接测试
- 无需担心参数匹配问题

---

## 💡 总结

| 诊断结果 | 说明 |
