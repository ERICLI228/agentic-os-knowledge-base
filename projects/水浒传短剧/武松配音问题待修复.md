# 武松配音沙哑问题待修复

**状态**：已冻结，待后续优化

**现象**：GPT‑SoVITS V3 推理输出的武松语音沙哑、模糊，调整 top_k/p/temperature 无效。

**疑似原因**：
1. 训练用参考音频质量不佳（可能存在底噪或口齿不清）
2. V3 模型在 CPU 推理下的稳定性不足

**后续修复方案**：
1. 收集 3-5 分钟高质量、干净、情绪饱满的武松语音样本
2. 降级到 GPT‑SoVITS V2 架构重新微调
3. 使用云端 GPU（如 AutoDL）完成训练，再下载到 Mac 推理

**临时替代方案**：
- 继续使用现有沙哑模型生成配音（至少能听清台词）
- 或切换至 Edge‑TTS 免费在线语音（牺牲角色一致性，换取清晰度）

**下次触发条件**：当用户明确要求修复武松声线时，调取此记录执行修复。
