## 三、恢复动态视频生成步骤

**前置条件**：Replicate 账户余额 ≥ $1

### Step 1：充值
访问 https://replicate.com/account/billing，点击 Add credit，充值 $5 或 $10。

### Step 2：验证余额
```bash
curl -H "Authorization: Token $(jq -r .replicate_api_token ~/AI_Short_Drama_Pipeline/config.json)" \
 https://api.replicate.com/v1/account | jq '.credit_balance'
```
预期返回 "5.00" 或更高。

### Step 3：运行动态生成
```bash
cd ~/AI_Short_Drama_Pipeline
python hybrid_pipeline.py \
 --story "武松打虎" \
 --episode 1 \
 --duration 30 \
 --output-dir ~/AI_Short_Drama_Pipeline/output/dynamic_$(date +%Y%m%d_%H%M%S)
```
系统将自动优先使用 Replicate 生成真正动态视频（成本约 $0.014/片段）。
