## 🔧 S1 训练 YAML 解析 Bug (20:30 PDT)

### 问题
S1 训练启动后立即崩溃：`TypeError: unsupported operand type(s) for -: 'str' and 'float'`
发生在 `lr_schedulers.py` 计算学习率衰减时：`(end_lr - peak_lr) / ...`

### 根因
- `s1_config.json` 使用 `yaml.full_load()` 加载
- YAML 将科学计数法 `2e-05` 解析为字符串 `'2e-05'` 而非浮点数
- `end_lr` 变成字符串，与 `peak_lr` (float) 相减报错

### 修复
将 `s1_config.json` 中的 `"lr_end": 2e-05` 改为 `"lr_end": 0.00002`
十进制表示法被 YAML 正确解析为 float

### 教训
**GPT-SoVITS 的 JSON 配置用 YAML 加载器解析！**
- 科学计数法在 YAML 中可能被解析为字符串
- 所有数值参数必须用十进制表示（`0.00002` 而非 `2e-05`）
- 修复前检查 checkpoint 中的 hyper_parameters 确认已有值类型正确
