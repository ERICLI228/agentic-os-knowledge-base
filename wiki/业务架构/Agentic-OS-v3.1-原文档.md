# Agentic OS v3.1 双业务线完整架构文档

> **设计原则**: 一个基座、两条业务线、独立运营、共享预算  
> **核心体验**: 一个指令启动 → 全程自动执行 → 关键节点审核 → 输出可发布成果  
> **版本**: v3.1 | **日期**: 2026-04-23  
> **备注**: 这是 v3.1 原版文档，v3.2 为增强版本

| 指标 | 正常范围 | 告警阈值 | 告警动作 |

| MS-5 | 人工审核 | 驾驶舱决策弹窗 | 通过/修改/驳回 | ⚠️ 强制人工 |
| MS-6 | 配音合成 | GPT-SoVITS / MiniMax TTS | 配音音频文件 | 否 |
| MS-7 | 视频合成 | FFmpeg | 最终 MP4 | 否 |
| MS-8 | 产出归档 | 本地文件系统 | 视频链接、剧本 TXT | 否 |

### 5.3 "一个指令启动"的交互流程

```
用户在指挥中心点击 "+新建短剧"
 │
 ├── 填写：故事主题、视觉风格、集数、目标时长
 │
 ▼
系统创建任务 (DRAMA-20260423-xxx)
 │
 ├── 自动调用 Dify API → 生成剧本 JSON
 ├── 自动调用 GLM → 争议检测与改写
 ├── 自动调用 ComfyUI → 生成角色图 + 视频片段
 │
 ▼
⚠️ 到达 MS-5 人工审核节点
 │
 ├── 驾驶舱弹窗：展示完整剧本 + 视频预览
 ├── 飞书通知：发送审核卡片
 │
 ├── 用户选择：
 │   ├── [通过] → 继续 MS-6
 │   ├── [修改] → 输入修改意见 → 回到 MS-1
 │   └── [驳回] → 任务终止，标记为 failed
 │
 ▼
自动执行 MS-6 (配音) → MS-7 (合成) → MS-8 (归档)
 │
 ▼
📦 驾驶舱展示最终视频链接，用户点击播放/下载
```

### 5.4 成本与效率路由策略

| 场景 | 优先方案 | 降级方案 | 选择逻辑 |
|------|---------|---------|---------|
| 剧本生成 | Dify + MiniMax | GLM API | 成本最低 |
| 常规视频场景 | 本地 Wan2.1 1.3B (免费) | Seedance API (付费) | 本地不可用时云端 |
| 关键特写镜头 | Seedance API | Wan2.1 14B 云端 | 质量优先 |
| 配音 | GPT-SoVITS 本地 | MiniMax TTS | 本地模型可用时优先 |
| 视频合成 | FFmpeg 本地 | - | 唯一方案 |
