## 一、Ralph 框架核心能力分析

### 1.1 Ralph 是什么

Ralph 是一个**AI 自主编码代理框架**，核心理念是：

> "让开发者放手方向盘，AI 才能真正驶向生产力革命的快车道"

**典型场景**:
```
凌晨两点，程序员小张将新功能 PRD 交给 Ralph 后关机回家。
次日晨会前，系统已自动生成完整代码、通过全部单元测试、
修复三处边界问题，并提交了整洁的 Pull Request。
```

### 1.2 Ralph 五大核心特性

| 特性 | 描述 | 实现方式 |
|------|------|---------|
| **① 轻量架构** | Bash 脚本驱动，不依赖重型框架 | `ralph.sh` + `prompt.md` |
| **② 自主循环** | AI 代理持续迭代直至完成全部 PRD | 循环执行 + 完成度检测 |
| **③ 状态持久化** | 通过 Git 与进度文件保存任务状态 | `progress.txt` + Git commits |
| **④ 工具兼容** | 支持 Amp、Claude Code 等主流 AI 编码工具 | 可插拔 AI 工具适配器 |
| **⑤ 闭环能力** | 自动完成编码→测试→修复→提交全流程 | 测试失败自动修复循环 |

### 1.3 Ralph 工作流程

```
┌─────────────────────────────────────────────────────────────────┐
│                      Ralph 自主循环流程                          │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  1️⃣ 初始化                                                       │
│     ├── 读取 PRD.md (需求文档)                                   │
│     ├── 读取 prompt.md (AI 工具提示模板)                          │
│     └── 创建 progress.txt (进度追踪)                             │
│                                                                  │
│  2️⃣ 自主循环 (直到 PRD 全部完成)                                  │
│     ├── 读取当前进度                                              │
│     ├── 调用 AI 工具执行下一步 (编码/测试/修复)                   │
│     ├── 运行测试验证                                              │
│     ├── 测试失败 → 自动修复循环                                   │
│     ├── 测试通过 → 提交 Git + 更新进度                            │
│     └── 检查 PRD 完成度 → 未完成则继续循环                        │
│                                                                  │
│  3️⃣ 完成                                                         │
│     ├── 生成完整代码                                              │
│     ├── 通过全部测试                                              │
│     └── 提交 Pull Request                                        │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

循环伪代码:
while (!prd_complete()) {
    ai_code = ai_generate(current_task);
    test_result = run_tests(ai_code);
    if (test_result.failed) {
        ai_fix = ai_fix_errors(test_result.errors);
    } else {
        git_commit(ai_code);
        update_progress();
    }
}
```

### 1.4 Ralph 使用方法

```bash
# 1. 下载 Ralph 脚本至项目 scripts 目录
mkdir -p scripts/ralph
cp ralph.sh scripts/ralph/
cp prompt.md scripts/ralph/

# 2. 给脚本添加执行权限
chmod +x scripts/ralph/ralph.sh

# 3. 编写 PRD 文档
cat > PRD.md << 'EOF'
# 功能需求
- 用户登录系统
- JWT 认证
- 密码加密存储
EOF

# 4. 启动 Ralph
bash scripts/ralph/ralph.sh

# 5. 设定即遗忘 (回家睡觉)
```

# progress_tracker.py
class ProgressTracker:
    def __init__(self, tasks):
        self.tasks = tasks
        self.completed = []
    
    def is_complete(self):
        return len(self.completed) == len(self.tasks)
    
    def update(self, task_id, status):
        if status == "passed":
            self.completed.append(task_id)

# auto_fix_loop.py
