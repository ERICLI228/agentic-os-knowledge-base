## 一、卡兹克写作系统核心能力分析

### 1.1 系统是什么

一套**自我进化的写作知识库系统**，核心理念：

> "让知识库从'被动仓库'升级为'主动汇报的系统'"

**典型场景**:
```
每天下午 5 点，系统自动：
1. 抓取 X 上 AI 相关点赞 TOP10 推文
2. 自动归档到 Obsidian AI NEWS HUB 文件夹
3. 调用 LLM Wiki Skill 将信息编译为认知地图
4. 微信推送日报（一句话总览 +100 字摘要 + 报告位置）

用户无需手动操作，只需每天查看微信日报即可。
```

### 1.2 三大核心流程

```
┌─────────────────────────────────────────────────────────────────┐
│              卡兹克写作系统流程                                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  步骤 1: 定时信息抓取 (Hermes + AutoCLI)                         │
│  ├── 无需 API KEY，复用 Chrome 登录态                            │
│  ├── 支持 90+ 站点信息抓取                                       │
│  ├── 每天下午 5 点定时执行                                        │
│  └── 产出：AI NEWS HUB/2026-04-23/x-ai-top10-daily.md           │
│                                                                  │
```

### 1.3 核心价值主张

|-----------|---------------|
| 手动筛选文章 | 自动抓取 TOP10 |

### 3.3 新增 Skill 设计

**位置**: `~/.agents/skills/karzke-writing-system-1.0.0/`

**文件结构**:
```
karzke-writing-system-1.0.0/
├── SKILL.md                    # Skill 说明
├── info_grabber.py             # 信息抓取器
├── wiki_compiler.py            # Wiki 编译器
├── daily_report_generator.py   # 日报生成器
└── writing_style_evolver.py    # 写作风格进化器 (可选)
```

**核心功能**:
```python
# info_grabber.py
def grab_daily_top10(sources, output_dir):
    """抓取每日 TOP10 内容"""
    # 支持 AutoCLI 或现有 proactive-operator
    articles = fetch_from_sources(sources)
    top10 = sort_by_engagement(articles)[:10]
    save_to_obsidian(top10, output_dir)
    return top10

# wiki_compiler.py
def compile_to_wiki(articles, style="karzke"):
    """将信息编译为 LLM Wiki"""
    # 调用 LLM 生成结构化知识地图
    wiki_content = llm_summarize(articles, style=style)
    save_wiki(wiki_content)
    return wiki_content

# daily_report_generator.py
def generate_daily_report(wiki_path, channels=["feishu", "wechat"]):
    """生成并推送日报"""
    summary = generate_summary(wiki_path)  # 一句话总览
    digest = generate_digest(wiki_path)    # 100 字摘要
    for channel in channels:
        send_report(channel, summary, digest, wiki_path)
```
