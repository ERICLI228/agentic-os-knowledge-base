### 失败原因

**Gradio API 参数映射问题**

尝试的 API 调用方式：
1. `client.predict(api_name="/change_tts_inference", ...)` → 返回空
2. `curl POST /gradio_api/call/change_tts_inference` → event_id 返回但执行 error
3. `curl POST /gradio_api/call/change_tts_inference_1` → event_id 返回但执行 error

**根本原因**: Gradio WebUI 的 API 需要复杂的组件状态映射，外部脚本难以正确传递所有 14+ 个参数。
