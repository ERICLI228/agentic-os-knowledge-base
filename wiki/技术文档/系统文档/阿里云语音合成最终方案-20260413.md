# 🎭 阿里云语音合成最终方案

> SDK安装有问题 → 推荐使用控制台或百炼语音

---

## 📊 问题诊断

| 问题 | 原因 |
|------|------|
| **SDK import失败** | pyenv Python 3.12有hashlib错误 |
| **包安装不完整** | aliyun-nls只有dist-info，无模块代码 |
| **系统Python限制** | PEP 668禁止pip安装 |

---

## ✅ 推荐方案

### 方案A：控制台手动生成（最简单）

**立即可用**:

```
https://nls-portal.console.aliyun.com/
项目 → water-margin-drama → 测试配音
```

**步骤**:

| 步骤 | 操作 |
|------|------|
| 1 | 登录智能语音交互控制台 |
| 2 | 点击项目 water-margin-drama |
| 3 | 输入文本："武松打虎台词" |
| 4 | 选择发音人：知锋 |
| 5 | 点击"测试" → "播放" |
| 6 | 点击"下载" → 保存MP3 |

**优势**:
- ✅ 无需SDK
- ✅ 立即可用
- ✅ 可试听选择声音
- ✅ 直接下载音频文件

---

### 方案B：百炼语音合成（角色更丰富）

**更多角色声音**:

```
https://bailian.console.aliyun.com/
模型 → 语音模型 → 语音合成 → 音色库
```

**可用声音**:

| 角色 | 百炼发音人 | 风格 |
|------|-----------|------|
| 武松 | 龙硕 | 博才干练男 |
| 宋江 | 龙高僧 | 得道高僧音 |
| 店小二 | 温润青年 | 温暖柔和 |

**优势**:
- ✅ 角色声音更丰富
- ✅ 更适合水浒传配音
- ✅ 控制台直接生成

---

### 方案C：获取Token后API调用

**步骤**:

| 步骤 | 操作 |
|------|------|
| 1 | 控制台首页 → 获取临时AccessToken |
| 2 | 复制Token（24小时有效） |
| 3 | 使用HTTP API或WebSocket调用 |
| 4 | 批量生成配音 |

**API调用方式**:

```python
# 使用Token调用WebSocket API
import websocket

ws_url = f"wss://nls-gateway.cn-shanghai.aliyuncs.com/ws/v1?token={TOKEN}"

# 发送TTS请求
{
  "appkey": "EO3zZigsTGKIUL1y",
  "text": "武松台词",
  "voice": "zhifeng",
  "format": "mp3"
}
```
