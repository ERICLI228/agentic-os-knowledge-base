**平台对比**:

| 平台 | 样本要求 | 成本 | 效果 | 推荐度 |
|------|---------|------|------|-------|
| **阿里云声音复刻** | 10秒-5分钟 | 已购资源包可用 | ⭐⭐⭐⭐ | ✅✅✅ 首选 |
| **讯飞配音** | 30秒以上 | 按量付费 | ⭐⭐⭐⭐⭐ | ✅✅ 备选 |
| **魔音工坊** | 1分钟以上 | ¥199/月 | ⭐⭐⭐⭐⭐ | ✅ 高质量 |

**阿里云声音复刻步骤**:
```
1. 准备央视配音音频样本
   - 来源：央视1998版水浒传视频片段
   - 要求：清晰干声、无背景音乐
   
2. 提取各角色声音样本
   - 武松（曲敬国）：打虎场景台词

   https://nls-portal.console.aliyun.com/
   → 声音复刻 → 创建专属发音人
   → 上传样本 → 等待训练（约1小时）
   → 获得专属发音人ID
   
4. 使用专属发音人ID生成配音
   voice="custom_wusong_001"（专属发音人ID）
```

### 方案C：专业后期处理（增强质感）

**工具**: Adobe Audition / Logic Pro X / Audacity

**关键处理步骤**:

| 步骤 | 作用 | 参数建议 |
|------|------|---------|
| **降噪** | 去除背景噪音 | 阈值-20dB |
| **均衡(EQ)** | 人声清晰饱满 | 低频+3dB、高频+2dB |
| **压缩** | 音量均匀、有质感 | 压缩比3:1 |
| **混响** | 空间感、真实感 | 混响时间0.5秒 |

**后期处理流程**:
```
1. 采样率48kHz、比特率24bit（高保真）
2. 降噪去除背景噪音
3. EQ调整频段（人声更清晰）
4. 压缩使音量均匀
5. 添加混响增加空间感
6. 混音导出高质量音频
```

方法B：配音演员访谈/纪录片
  → 搜索"曲敬国 赵述仁 配音"
  → 提取访谈中的声音样本
