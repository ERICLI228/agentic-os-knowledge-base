## 💡 配音生成改进要点

### 1. 使用男声发音人

**当前问题**: `voice="xiaoyun"` 是女声

**解决**: 控制台查看发音人下拉列表，选择知锋、知冰等男声

---

### 2. 应用央视风格参数

```python
# 武松配音
synthesizer.start(
    "景阳冈上，三碗不过冈！",
    voice="zhifeng",  # 男声（需确认正确ID）
    speech_rate=50,   # 中速偏快
    pitch_rate=20,    # 高昂
    volume=70         # 洪亮
)

# 宋江配音
synthesizer.start(
    "兄弟们，梁山聚义，替天行道！",
    voice="zhibing",  # 男声（需确认正确ID）
    speech_rate=-30,  # 中速偏慢
    pitch_rate=-10,   # 沉稳
    volume=50         # 温和
)
```
