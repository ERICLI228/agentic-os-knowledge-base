## 📝 第四步：创建配音脚本

### 4.1 配音脚本位置

**已有脚本**: `~/.openclaw/skills/water-margin-drama/drama_voice_sambert_v2.py`

### 4.2 环境变量配置

**创建**: `~/.openclaw/.env.sambert`

```bash
# 阿里云Sambert API配置
ALIYUN_ACCESS_KEY_ID=你的AccessKey_ID
ALIYUN_ACCESS_KEY_SECRET=你的AccessKey_Secret（绝密）
ALIYUN_APP_KEY=你的项目AppKey
ALIYUN_REGION=cn-shanghai
```

**⚠️ 安全存储**:
```bash
# 添加到.gitignore
echo ".env.sambert" >> ~/.openclaw/.gitignore
chmod 600 ~/.openclaw/.env.sambert
```
